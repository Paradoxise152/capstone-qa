## LangGraph 部署指南

### 环境要求
- Python 3.12+
- PostgreSQL 15+（生产环境推荐）
- Redis 7+（可选，用于缓存）

### 本地部署步骤
1. `pip install langgraph`
2. 创建 `agent.py`：定义 StateGraph
3. `python agent.py` 启动

### 生产部署
推荐使用 Docker Compose 部署：
```yaml
services:
  agent:
    image: langgraph/agent:latest
    ports: ["8000:8000"]
  postgres:
    image: postgres:15
```
健康检查端点：`GET /health`

## 工单系统使用指南

### 创建工单
在客服后台→工单管理→新建工单，填写：
- 标题：问题简述
- 分类：技术/产品/账单/其他
- 优先级：低/中/高/紧急

### 查询工单
在搜索栏输入工单号（格式 TK-YYYY-XXXXX）或关键词。

### 工单状态
- 待处理：新创建的工单
- 处理中：客服已接单
- 已完成：问题已解决
- 已关闭：超过 7 天未回复自动关闭
